# 牛顿色环 · 色彩染缸

904×572 的纯 Canvas 互动原型，无框架、无外部素材、无运行时依赖。

## 操作

- 点击上方横向牛顿色环：切换当前投染色。
- 色环最右端的“清除”段：切换清除色；长按染缸会把经过的区域擦成无色。
- 点按染缸：吸取指针位置的混合色，成为当前颜色。
- 拖动染缸：以拖动的幅度和方向推动局部流体；顶部“陀螺仪”按钮可请求设备运动权限。
- 倾斜/摇晃设备：陀螺仪与运动传感器会把姿态和加速度变化转换为染缸受力；未支持传感器时仍可用拖动操作。
- 长按染缸：持续播撒当前颜色；长按时拖动可同时改变流向。
- `R`：复位；方向键：微调当前色；空格：快速投染一滴。

## 运行

直接打开 `index.html` 即可。托管版本的静态入口位于 `dist/index.html`。
